# 编写实现计划

> **核心原则：零上下文假设 + 细粒度拆解 = 可执行计划**

---

## 铁律

> **`NO CODE WITHOUT A PLAN FIRST`**

对于任何需要多步完成的功能开发，必须先写计划，再碰代码。

---

## 原则

### 假设执行者零代码库上下文

你的执行者（可能是子 Agent 或未来的你）没有看过这个代码库。你的计划必须记录他们需要知道的一切：

- 每个任务要**修改哪些文件**（完整路径）
- 需要**阅读哪些现有代码**来理解模式
- **怎么写测试**（测试文件路径 + 测试内容要点）
- **怎么验证**（运行什么命令）
- **检查什么文档**来了解约定

### 2-5 分钟任务粒度

每个步骤应该是一个单一操作，耗时不超过 5 分钟。

**反例**（粒度太粗）：
```
1. 实现用户注册功能
```

**正例**（粒度合适）：
```
1. 编写 UserRegistrationTest — 测试正常注册
2. 运行测试确认失败
3. 实现 UserService.register() 最简版本
4. 运行测试确认通过
5. 提交
```

## 工作流程

```
设计文档（来自 brainstorming）
    │
    ▼
┌───────────────────────────┐
│  Step 1: 分析设计文档       │
│  (理解功能范围、技术选型、     │
│   数据结构)                 │
└───────────┬───────────────┘
            │
            ▼
┌───────────────────────────┐
│  Step 2: 探索相关代码       │
│  (找到需要修改和参考的       │
│   现有文件)                 │
└───────────┬───────────────┘
            │
            ▼
┌───────────────────────────┐
│  Step 3: 拆解任务           │
│  (按 TDD 节奏拆解为         │
│   2-5 分钟微任务)           │
└───────────┬───────────────┘
            │
            ▼
┌───────────────────────────┐
│  Step 4: 标注依赖关系       │
│  (哪些任务可并行?           │
│   哪些有前置依赖?)          │
└───────────┬───────────────┘
            │
            ▼
┌───────────────────────────┐
│  Step 5: 输出计划文档       │
│  (保存到 docs/plans/       │
│   等待用户确认)             │
└───────────────────────────┘
```

## 计划文档模板

```markdown
# [功能名称] 实现计划

> **日期**: YYYY-MM-DD
> **来源设计**: docs/plans/YYYY-MM-DD-xxx-design.md

## 目标
一句话描述这个计划要构建什么

## 架构
2-3 句话描述实现方法

## 技术栈
涉及的关键技术/库

## 前置依赖
- 依赖 1: [任务编号或描述]
- 依赖 2: [任务编号或描述]

## 执行选项

| 方式 | 说明 |
|------|------|
| **Subagent 模式** | 每任务派发独立子 Agent，自动双阶段审查 |
| **批量执行模式** | 当前会话中批量执行，每批后人工确认 |

## 任务清单

### 任务 1: [任务名称]

| 项目 | 内容 |
|------|------|
| **文件** | `src/main/java/.../XxxService.java` |
| **前置** | 无 |
| **步骤** | ① 编写 [功能] 单元测试 → ② 运行确认失败 → ③ 实现最简代码 → ④ 运行确认通过 → ⑤ 提交 |
| **验证** | `mvn test -Dtest=XxxServiceTest` |

### 任务 2: [任务名称]
...

## 依赖关系图

```
任务 1 ──→ 任务 2 ──→ 任务 4
             │
             └──→ 任务 3 ──→ 任务 5 (可并行)
```
