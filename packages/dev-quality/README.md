# Dev Quality Suite

> 代码审查与质量保障套件

## Skills 目录

### Bug 分析
| Skill | 说明 | 源位置 |
|-------|------|--------|
| bug-analyzer | Bug 分析与复盘 | `skill-dev-bug/` |

### 代码审查
| Skill | 说明 | 源位置 |
|-------|------|--------|
| code-reviewer | 全栈代码审查 | `skill-dev-review/` |
| frontend-code-review | 前端专项审查 | `skill-dev-review-frontend/` |
| pr-review | PR 代码评审 | `skill-dev-review-pr/` |

### 设计评审
| Skill | 说明 | 源位置 |
|-------|------|--------|
| design-reviewer | 详细设计评审 | `skill-dev-design-reviewer/` |

### 测试
| Skill | 说明 | 源位置 |
|-------|------|--------|
| test-gen | 单元测试生成 | `skill-dev-test/` |

## 使用方式

```bash
# Bug 分析
/bug-analyzer

# 代码审查
/code-reviewer

# PR 审查
/pr-review

# 设计评审
/design-reviewer
```

## 安装说明

这些 Skills 会自动从 Claude Code Skills 市场加载，也可以手动复制到：

```
~/.claude/skills/
```
