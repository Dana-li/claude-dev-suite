# Bug 分析流程

## 第一步：复现确认
1. 理解错误信息（异常类型、堆栈）
2. 定位相关日志文件
3. 确认复现步骤

## 第二步：根因分析
1. 定位问题代码（使用 Read, Grep）
2. 分析调用链路
3. 找出根本原因

## 第三步：修复方案
1. 提出修复方案
2. 评估影响范围
3. 编写修复代码

## 第四步：复盘输出
修复完成后，输出复盘文档到 `docs/bug-fix/`

## 使用方式

| 场景 | 触发方式 |
|------|----------|
| Bug 修复 | `/dev-bugfix` |
| 独立使用 | `/skill-dev-bug` |

## 输出模板

```markdown
# Bug 复盘：[问题简述]

## 问题描述
[详细描述]

## 复现步骤
1. [步骤1]
2. [步骤2]

## 根因分析
[根本原因]

## 解决方案
[如何修复]

## 预防措施
[如何避免类似问题]
```
