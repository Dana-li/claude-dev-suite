# 代码审查 Skill

## 审查范围

### Java/Spring Boot
- 代码规范（命名、注释、格式）
- 安全漏洞（SQL注入、XSS、越权）
- 性能问题（N+1查询、循环查询）
- 异常处理
- 日志规范

### Vue/前端
- 组件设计
- 响应式规范
- 状态管理
- 性能优化
- 安全最佳实践

## 审查维度

| 维度 | 权重 | 检查项 |
|------|------|--------|
| 正确性 | 30% | 逻辑正确、空指针、边界条件 |
| 可读性 | 20% | 命名规范、注释清晰、函数长度 |
| 安全性 | 25% | 注入、越权、敏感数据 |
| 性能 | 15% | 数据库、缓存、算法复杂度 |
| 可维护性 | 10% | 耦合度、重复代码、测试覆盖 |
